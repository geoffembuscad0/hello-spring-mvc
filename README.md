# Hello Spring

A simple Spring MVC web application built with Spring Boot, Thymeleaf, Tailwind CSS, and MySQL. This project is part of my journey learning Java Spring Boot and web application development.

## Features

- Landing page
- User login and authentication
- User dashboard
- Logout functionality
- Responsive navigation:
  - Mobile (720px and below): Sidebar menu
  - Tablet and desktop (above 720px): Top navigation menu
- MySQL database integration

## Tech Stack

- **Backend:** Java 21, Spring Boot, Spring MVC
- **Frontend:** Thymeleaf, Tailwind CSS
- **Database:** MySQL
- **Build Tool:** Maven

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/hello-spring.git
   ```

2. Configure your MySQL database and application credentials.

3. Install frontend dependencies:
   ```bash
   npm install
   ```

4. Start Tailwind CSS in watch mode:
   ```bash
   npm run dev
   ```

5. Run the Spring Boot application through Eclipse or Maven:
   ```bash
   ./mvnw spring-boot:run
   ```

6. Open your browser:
   ```text
   http://localhost:8080
   ```
